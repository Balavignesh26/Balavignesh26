### 🫀 CardioSense: Self-Supervised ECG Analysis
> PyTorch Lightning **ResNet1D-18** for 12-lead ECG: multi-label classification (5 superclasses) plus biological age regression through a shared 512-D latent space with Homoscedastic Uncertainty Loss. Masked Signal Modeling pretraining pushed it to **0.91 macro-AUROC** and **~9-10 yr MAE**, beating the supervised baseline.

### 🌐 NetHealth: Industrial Network Diagnostics
> Cross-layer (L1-L7) diagnostics over 10+ KPIs using **Isolation Forest** and **Bayesian Networks**, rolled into a single **"ONE Score"** health metric. A topology-aware root cause engine (**Granger causality** + dependency graphs) cuts false-positive alert propagation and reduces MTTR.

### 🚗 Smart Parking System
> Real-time vehicle detection and license plate recognition with **YOLOv8 + SORT**, handling entry/exit tracking and parking management automatically.
